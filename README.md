# Spendly — мобильное приложение учёта расходов

**Живое демо (веб-сборка в рамке телефона):** https://shelt00n.github.io/spendly-mobile/

![Spendly](docs/cover.png)

Кроссплатформенное приложение для iOS, Android и Web на одной кодовой базе: баланс, месячный бюджет, быстрый ввод операций и статистика. Проект демонстрационный, данные тестовые.

## Возможности

- **Главный экран**: баланс со скрытием суммы, доходы и расходы, прогресс месячного бюджета с предупреждением о перерасходе, топ-3 категории трат.
- **Добавление операции**: нижняя шторка, своя цифровая клавиатура с валидацией ввода, переключатель «расход / доход», категории-чипсы, комментарий.
- **Статистика**: столбчатый график за 7 дней с подсветкой сегодняшнего дня, доли категорий с прогресс-барами, отдельно расходы и доходы.
- **Удаление** операции долгим нажатием.
- **Плавающий таб-бар** с центральной FAB-кнопкой.

## Технические решения

- Состояние на `useReducer`: операции добавления и удаления описаны типизированными экшенами.
- Расчёты (баланс, бюджет, агрегации по дням и категориям) мемоизированы через `useMemo`.
- Дизайн-токены (`src/theme.ts`): цвета, радиусы, тени для iOS и Android.
- Только core-компоненты React Native и `expo-linear-gradient`, без тяжёлых UI-китов.
- Веб-версия собирается через `react-native-web` и публикуется на GitHub Pages.

## Стек

`React Native 0.88` · `Expo SDK 58` · `TypeScript (strict)` · `react-native-web` · `expo-linear-gradient`

## Запуск

```bash
git clone https://github.com/Shelt00n/spendly-mobile.git
cd spendly-mobile
npm install
npx expo start          # QR-код для Expo Go на телефоне, i — iOS-симулятор, a — Android
npx expo start --web    # версия для браузера
```

Сборка веб-демо:

```bash
npx expo export --platform web --output-dir dist-web
```

## Структура

```
App.tsx                    — корень, таб-бар, reducer операций
src/screens/HomeScreen.tsx — баланс, бюджет, список операций
src/screens/StatsScreen.tsx— график за неделю и категории
src/components/AddSheet.tsx— шторка добавления с цифровой клавиатурой
src/components/Ui.tsx      — общие компоненты (строка операции, прогресс-бар)
src/data.ts                — категории, тестовые данные, форматирование
src/theme.ts               — дизайн-токены
docs/                      — витрина и веб-сборка для GitHub Pages
```
